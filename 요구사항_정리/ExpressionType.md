# Expression 종류 

| 분류    | 클래스            | 설명                      | 예시                        |
| ----- | -------------- | ----------------------- | ------------------------- |
| 리터럴   | `LiteralExpr`  | 리터럴 값을 그대로 표현하는 노드      | `10`, `"hello"`, `true`   |
| 변수    | `VariableExpr` | 변수(식별자)를 참조하는 노드        | `a`, `count`              |
| 대입    | `AssignExpr`   | 변수에 값을 대입하는 노드          | `a = 3`                   |
| 단항 연산 | `UnaryExpr`    | 하나의 피연산자를 사용하는 연산       | `-a`, `!flag`             |
| 이항 연산 | `BinaryExpr`   | 두 개의 피연산자를 사용하는 연산      | `a + b`, `a * b`, `a > b` |
| 논리 연산 | `LogicalExpr`  | `and`, `or` 연산을 수행하는 노드 | `a and b`, `x or y`       |
| 그룹화   | `GroupingExpr` | 괄호로 우선순위를 지정하는 노드       | `(a + b)`                 |
