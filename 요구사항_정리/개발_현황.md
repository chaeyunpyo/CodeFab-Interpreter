# 개발 현황

코드 기준(md 문서 서술이 아니라 `src/` 실제 구현)으로 확인한 현재 진행
상황이다. 확인 시점: 2026-07-08, `feature/checker` 브랜치(`master` 최신
병합 반영, instanceof AstBuilder 파싱·CLI 구조 개편 포함). 팀 전체
Python 3.14 사용 확정.

## 현재 현황 (한눈에 보기)

| 분류 | 상태 | 비고 |
| --- | --- | --- |
| function | ✅ 완료 | Assembler/Checker/Executor 전부 구현 |
| class | ✅ 완료 | instanceof까지 포함해서 전부 구현됨 |
| import | 🟡 부분 완료 | Checker 몫은 전부 완료, 파일 로더/순환 감지(Assembler)만 미구현 |
| 정적배열 | ✅ 완료 | - |
| 공장제어쉘 | ✅ 완료 | `prompt_shell/` → `cli/` 구조 개편 완료 (기능 변화 없음) |
| 실행전 최적화 | 🟡 부분 완료 | Checker 몫(거리 계산+상수 폴딩)은 완료, Executor 연동/검증 미착수 |

## 앞으로 할 일 (역할별)

`요구사항_정리/개발_순서.md`의 역할 분담 기준.

| 역할 | 할 일 | 관련 기능 |
| --- | --- | --- |
| Assembler (1명) | import 대상 파일을 읽어 재귀적으로 조립하는 로더 구현, import 문법 오류·파일 없음·순환 import 감지 | import |
| Executor (1명) | Checker가 계산한 `checker.locals`의 거리로 변수를 조회하도록 조회 로직 변경 | 실행전 최적화 |
| Executor (필요시) | alias 네임스페이스 접근 지원 | import |
| 전원 | Test Double로 "스코프를 안 거슬러 올라가는지" / "연산 횟수가 0이 되는지" 검증 | 실행전 최적화 |

## 기능별 상세 현황

### function — 완료

| 영역 | 상태 |
| --- | --- |
| Assembler (파싱) | 완료 (`_statement_parser.py`, `_expression_parser.py`) |
| Checker (정적 오류 2종) | 완료 (`checker.py`) |
| Executor (실행, 재귀 포함) | 완료 (`_function.py`의 `Function`/`LoxCallable`, `_signals.py`의 `ReturnSignal`) |

### class — 완료

| 영역 | 상태 |
| --- | --- |
| 클래스 선언/인스턴스 생성 | 완료 |
| 필드 읽기/쓰기 | 완료 (`FieldGetExpr`/`FieldSetExpr`) |
| 메서드/생성자(init)/상속/super | 완료 (`LoxClass`/`LoxInstance`, `_class.py`) |
| Checker 정적 오류 5종 | 완료 |
| 런타임 오류 4종 | 완료 (`NotAClassError`, `NotAnInstanceError`, `UndefinedPropertyError`) |
| instanceof 연산자 | 완료 — Assembler 파싱(`_expression_parser.py`의 `_finish_instanceof`)이 추가되면서 Node/Executor 평가(`_evaluate_instanceof`)까지 end-to-end로 연결됨 |

### import — 부분 완료

| 영역 | 상태 |
| --- | --- |
| Assembler — 문법 파싱, 경로 STRING 제한 | 완료 |
| Assembler — 파일 로더(재귀 조립), 문법 오류/파일 없음/순환 import 감지 | **미구현** — `요구사항_정리/개발_순서.md` 기준 이 부분은 Assembler 담당인데 아직 코드 없음 |
| Checker — 같은 scope 중복 import | 완료 |
| Checker — alias 이름 충돌 | 완료 |
| Checker — 반복문 내부 import | 완료 |
| Checker — 상위 level 중복 import 금지 | 완료 — `ScopeChecker`에 `parent` 체인을 추가해서 조상 스코프까지 검사 |
| Executor — alias 네임스페이스 접근 | 미구현 (경미한 범위, 로더가 먼저 필요) |

### 정적배열 — 완료

토큰, `IndexGetExpr`/`IndexSetExpr`, 런타임 오류 4종(`IndexOutOfRangeError`,
`InvalidIndexTypeError`, `NotAnArrayError`, `InvalidArraySizeError`),
`ArrayBuiltin`/`FabArray` 전부 구현되어 있다.

### 공장제어쉘 — 완료

3가지 실행 모드(Prompt/File/Debug)와 디버그 명령 10종(step/next/continue/
breakpoint/watch/inspect 등) 전부 구현되어 있다. `src/prompt_shell/`이
`src/cli/`로 구조 개편됨(`_main.py`/`_repl.py`/`_file_mode.py`/
`_debug_mode.py`로 파일 분리, 기능 변화 없음).

### 실행전 최적화 — 부분 완료

| 영역 | 상태 |
| --- | --- |
| Checker — 정적 바인딩(변수 거리 계산) | 완료 — `checker.locals`에 `id(Expr) -> distance` 기록 |
| Checker — 상수 연산 최적화(수식 합치기) | 완료 — 리터럴로만 구성된 Binary/Unary/Grouping을 in-place로 `LiteralExpr` 치환 |
| Executor — 계산된 거리로 변수 조회 | 미착수 |
| Test Double 검증 2종 | 미착수 (Executor 연동이 먼저 필요) |
