## ✅ kw_only 호환성 이슈 (해결됨) — 개발 환경은 Python 3.14 사용

`src/nodes/stmt.py`의 모든 Stmt 클래스가 아래처럼 `line` 필드를 선언한다.

```python
line: int = field(default=1, kw_only=True, compare=False)
```

`dataclasses.field()`의 `kw_only` 옵션은 **Python 3.10부터** 지원된다.
`pyproject.toml`에 `requires-python = ">=3.14"`로 이미 명시되어 있는데,
로컬 개발 환경에 Python 3.9.13만 설치되어 있어서 `nodes` 패키지를
import하는 순간 아래 오류로 죽었었다.

```
TypeError: field() got an unexpected keyword argument 'kw_only'
```

**코드나 프로젝트 설정 문제가 아니라 로컬 환경이 프로젝트 요구 버전보다
뒤처져 있던 것이었다.** Python 3.14를 설치해서 해결했고, 팀 전체가 3.14를
쓰기로 확정했다. `master` 최신 병합 후 3.14 기준으로 전체 테스트(522개)
통과 확인함.

## 기능별 진행 상황

### function — 완료

| 영역 | 상태 |
| --- | --- |
| Assembler (파싱) | 완료 (`_statement_parser.py`, `_expression_parser.py`) |
| Checker (정적 오류 2종) | 완료 (`checker.py`) |
| Executor (실행, 재귀 포함) | 완료 (`_function.py`의 `Function`/`LoxCallable`, `_signals.py`의 `ReturnSignal`) |

### class — 완료

| 영역 | 상태 |
| --- | --- |
| 클래스 선언/인스턴스 생성 | 완료 |
| 필드 읽기/쓰기 | 완료 (`FieldGetExpr`/`FieldSetExpr`) |
| 메서드/생성자(init)/상속/super | 완료 (`LoxClass`/`LoxInstance`, `_class.py`) |
| Checker 정적 오류 5종 | 완료 |
| 런타임 오류 4종 | 완료 (`NotAClassError`, `NotAnInstanceError`, `UndefinedPropertyError`) |
| instanceof 연산자 | 완료 — Assembler 파싱(`_expression_parser.py`의 `_finish_instanceof`)이 추가되면서 Node/Executor 평가(`_evaluate_instanceof`)까지 end-to-end로 연결됨 |

### import — Assembler/Checker는 진행, Executor는 미착수

| 영역 | 상태 |
| --- | --- |
| Assembler (문법 파싱, 경로 STRING 제한) | 완료 |
| Checker — 같은 scope 중복 import | 완료 |
| Checker — alias 이름 충돌 | 완료 |
| Checker — 반복문 내부 import | 완료 |
| Checker — **상위 level 중복 import 금지** | **미구현** — import.md 세부 규칙에 명시되어 있으나, 현재 `imported_paths`는 스코프별로만 관리되어 상위 스코프에서 이미 import한 파일을 하위에서 다시 import해도 잡히지 않는다 |
| Checker — import 문법 오류 / 파일 없음 / 순환 import | Assembler 담당으로 분류됨 (미검증, 별도 확인 필요) |
| Executor (파일 읽기/조립/alias로 실제 접근/순환 import 감지) | **미착수** — `src/executor/`에 `ImportStmt` 처리 코드가 전혀 없음 |

### 정적배열 — 완료

토큰, `IndexGetExpr`/`IndexSetExpr`, 런타임 오류 4종(`IndexOutOfRangeError`,
`InvalidIndexTypeError`, `NotAnArrayError`, `InvalidArraySizeError`),
`ArrayBuiltin`/`FabArray` 전부 구현되어 있다.

### 공장제어쉘 — 완료

3가지 실행 모드(Prompt/File/Debug)와 디버그 명령 10종(step/next/continue/
breakpoint/watch/inspect 등) 전부 구현되어 있다. `src/prompt_shell/`이
`src/cli/`로 구조 개편됨(`_main.py`/`_repl.py`/`_file_mode.py`/
`_debug_mode.py`로 파일 분리, 기능 변화 없음).

### 실행전 최적화 — 미착수

`distance`/resolve/상수 폴딩 등 관련 로직이 `src/` 어디에도 없다. 착수 전.
