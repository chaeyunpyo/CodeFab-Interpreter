# [추가] 정적 배열 구현 항목

## 구현해야 할 기능

| 분류 | 항목 | 설명 | 예시 |
| --- | --- | --- | --- |
| 배열 생성 | 고정 크기 배열 생성 | 생성 시 크기가 확정되고 각 칸은 null로 초기화 | `var arr = Array(3); // [null, null, null]` |
| 배열 접근 | 인덱스 읽기 | 인덱스로 값을 조회 | `print arr[0];` |
| 배열 접근 | 인덱스 쓰기 | 인덱스에 값을 대입 | `arr[0] = 10;` |
| Token | LEFT_BRACKET | 인덱스 시작 토큰 `[` | `arr[0]` |
| Token | RIGHT_BRACKET | 인덱스 종료 토큰 `]` | `arr[0]` |
| Expr | 배열 읽기 표현식 | 인덱스 읽기용 Expr | `v = arr[i];` |
| Expr | 배열 쓰기 표현식 | 인덱스 쓰기용 Expr | `arr[i] = 7;` |

## 구현해야 할 오류 검사 (런타임)

| 분류 | 항목 | 설명 | 예시 |
| --- | --- | --- | --- |
| 런타임 오류 | 인덱스 범위 초과 | 배열 크기를 벗어난 인덱스 접근 | `print arr[5];` |
| 런타임 오류 | 인덱스 타입 오류 | 인덱스가 숫자가 아님 | `print arr["hello"];` |
| 런타임 오류 | 대상 타입 오류 | 배열이 아닌 값에 `[]` 사용 | `var x = 10; print x[0];` |
| 런타임 오류 | 크기 타입 오류 | 배열 생성 시 크기가 숫자가 아님 | `var brr = Array("hi");` |
