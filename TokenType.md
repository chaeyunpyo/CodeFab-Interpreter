# Token 종류 요약

| 분류        | 개수 | 설명                                                                |
| --------- |---:|-------------------------------------------------------------------|
| 괄호        | 4개 | `(`, `)`, `{`, `}`                                                |
| 구분자       | 1개 | `;`                                                               |
| 산술 연산자    | 4개 | `+`, `-`, `*`, `/`                                                |
| 대입/비교 연산자 | 8개 | `=`, `>`, `<`, `==`, `>=`, `<=`, `=<`, `=>`                        |
| 단항 연산자    | 2개 | `!`, `!=`                                                          |
| 예약어       | 9개 | `var`, `if`, `else`, `for`, `print`, `true`, `false`, `and`, `or` |
| 식별자       | 1개 | 변수 또는 함수 이름                                                       |
| 리터럴       | 2개 | 숫자(`NUMBER`), 문자열(`STRING`)                                       |
| 종료 토큰     | 1개 | `EOF`                                                             |
